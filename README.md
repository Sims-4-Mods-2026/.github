## ⚡ Quick Start

1. Download the mod archive from the link above.
2. Extract the files. Keep `.package` and `.ts4script` files in their original formats.
3. Place compatible mod files in the `Documents/Electronic Arts/The Sims 4/Mods` folder, then enable Custom Content and Mods and Script Mods in Game Options.

Restart the game after changing mod settings or installing new content.

## ❓ FAQ

**Do I need to run mods as Administrator?**

No — standard user access is normally sufficient to copy mod files into your user Documents folder.

**Can antivirus software flag mod files?**

Some security tools may flag unfamiliar script files. Check the source and review detections before allowing or using a file.

**Do Sims 4 Mods work on Windows 11?**

The game supports Windows PCs. Individual mods may have separate requirements, so check their compatibility information.

**Where do I install custom content and script mods?**

Place supported `.package` and `.ts4script` files in the Sims 4 Mods folder inside your Documents directory.

**Do mods need updates after a game patch?**

Some mods require updates after game patches. Check each creator's compatibility notes and remove or update outdated files when necessary.
